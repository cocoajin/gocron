## GoCron 2.0.0

- 数据库存储改为 SQLite，首次安装自动建库建表，无需 MySQL 或 PostgreSQL 服务。
- 保留原任务、节点、日志、用户和通知管理功能，升级 Vue 3、Element Plus 和 Vite。
- 账号密码登录，邮箱选填；密码仅要求非空，无长度门槛。
- 新密码使用 Argon2id，兼容旧 MD5 用户成功登录后自动升级。
- 升级 JWT v5、gRPC、xorm、SQLite 驱动等 Go 依赖。
- 修复单实例任务并发执行、panic 状态及 Shell 超时清理等问题。

## 下载与使用

提供 Linux amd64、Linux arm64 和 Windows amd64 压缩包，每个包包含调度器、执行节点及使用说明。管理页面和 SQLite 已编译进程序，无需单独部署前端或数据库服务。SHA256SUMS 用于校验下载文件。

解压后运行 `gocron web`（Windows 使用 `gocron.exe web`），访问 `http://127.0.0.1:5920` 完成首次安装。Shell 任务另需启动包内的 `gocron-node`。

本版本完成构建发布，跨平台运行行为仍需实际环境验证。不包含旧 MySQL/PostgreSQL 数据自动导入工具。
